# qkquant 可视化设计文档

## 概述

为策略回测和持仓跟踪提供可视化能力，帮助快速判断策略质量和组合状态。基于现有 matplotlib 生态，输出 PNG 静态图表；可选 HTML 交互版。

---

## 一、回测可视化

### 1.1 策略净值曲线 + 回撤

**用途**：一眼看策略赚不赚钱、波动大不大。

```
┌──────────────────────────────────────┐
│  上子图: 净值曲线                      │
│  - 策略净值 (蓝色实线)                 │
│  - HS300 等权基准 (灰色虚线)           │
│  - 标注买卖点 (▲买入  ▼卖出)           │
│                                      │
│  下子图: 回撤阴影                      │
│  - 当前回撤 (红色填充)                 │
│  - 标注最大回撤点和熔断事件            │
└──────────────────────────────────────┘
```

**数据来源**：
- `BacktestEngine.run()` 返回的 `analyzers["timereturn"]` → 每日收益率序列
- `analyzers["drawdown"]` → 回撤数据
- `strategy._trade_log` → 买卖点

### 1.2 月度收益热力图

**用途**：看策略是否有季节性特征，哪几个月在亏钱。

```
       Jan  Feb  Mar  Apr  May  Jun  Jul  Aug  Sep  Oct  Nov  Dec
2023   -   -   +2%  -1%  +5%  +3%   -    -    -    -    -    -
2024   +1% +4%  -2%  -3%  +6%  -1%  +8%  -4%  +2%  +3%  -1%  +5%
2025   +3%  -1%  +4%  +7%  -2%  -3%

绿色 = 盈利月，红色 = 亏损月，颜色深浅 = 幅度大小
```

### 1.3 交易分布

**用途**：单笔交易的盈亏分布和持有周期。

```
左图: 盈亏分布直方图
  - x轴: 收益率区间
  - y轴: 交易笔数
  - 红色 = 亏损，绿色 = 盈利
  - 标注平均盈亏、盈亏比

右图: 持有天数分布
  - x轴: 持有天数
  - y轴: 交易笔数
  - 标注平均持有天数
```

### 1.4 策略对比

**用途**：多个策略同区间跑，横向对比净值曲线。

```
一张图，多条净值曲线（不同颜色）：
- momentum:         +22.35%  (蓝色)
- ma_boll:           +3.12%  (橙色)
- momentum_breakout: +15.67%  (绿色)
- HS300等权:          -5.44%  (灰色虚线)
```


### 2.2 个股权重和收益矩阵

**用途**：一眼看到哪只票贡献了最多收益/亏损。

```
散点图:
  x轴: 持仓权重
  y轴: 累计收益
  每个点 = 一只持仓
  大小 = 持仓天数
  颜色 = 行业

  → 右上角 = 重仓 + 大赚（生益科技）
  → 左下角 = 轻仓 + 小亏
  → 右下角 = 重仓 + 亏损（需要关注！）
```

### 2.3 基准偏离追踪

**用途**：看你的持仓相对 HS300 的超额从哪来。

```
上: 持仓加权收益曲线 (蓝) vs HS300 (灰)
下: Alpha 累计 (持仓收益 - HS300 收益)
   绿色 = 跑赢期，红色 = 跑输期
```

## 三、实现方案

### 技术选型

| 方案 | 静态图片 | 交互式 | 改动量 |
|------|:---:|:---:|:---:|
| **matplotlib** (已有) | ✅ | ❌ | 小 |
| **plotly** | ✅ | ✅ | 中 |
| **streamlit** Web 面板 | ✅ | ✅ | 大 |

**推荐先用 matplotlib**，产出静态 PNG 嵌入 markdown 报告。后续再加 plotly 交互版。

### 文件结构

```
src/qkquant/viz/
├── __init__.py
├── backtest_viz.py    # 回测图表
│   ├── plot_equity_curve()
│   ├── plot_monthly_heatmap()
│   ├── plot_trade_distribution()
│   └── plot_strategy_compare()
├── portfolio_viz.py   # 持仓图表
│   ├── plot_holdings_summary()
│   ├── plot_weight_return_scatter()
│   └── plot_alpha_tracking()
└── report.py          # 报告整合
    └── generate_viz_report()  → 输出 PNG + markdown
```

### 数据接口

所有图表函数接受 `pd.DataFrame` 或 dataclass，不依赖 BacktestEngine 实例，方便未来实盘复用：

```python
# 回测图表
def plot_equity_curve(
    daily_returns: pd.Series,      # index=date, values=daily_return
    benchmark_returns: pd.Series | None = None,
    trades: list[dict] | None = None,  # [{date, side, code, price}]
    title: str = "Strategy Equity Curve",
) -> plt.Figure:
    ...

# 持仓图表
def plot_holdings_summary(
    holdings: list[dict],           # [{code, name, cost, current, qty, pnl_pct, industry}]
    benchmark_return: float = 0,
    title: str = "Portfolio Overview",
) -> plt.Figure:
    ...
```

### 集成方式

1. **回测报告**：`qkquant backtest momentum --viz` → 在 `reports/backtest_momentum_xxx/` 下额外生成 PNG
2. **持仓推送**：`qkquant track --push` 在推送文本前先生成持仓概览图（Server酱支持图片）
3. **独立命令**：`qkquant dashboard` → 生成完整 HTML 报告

## 四、优先级和实施顺序

| 优先级 | 图表 | 用途 | 预计工时 |
|:---:|------|------|:---:|
| P0 | 净值曲线 + 回撤 | 最基础，回测必看 | 小 |
| P0 | 持仓概览面板 | 每天推送用 | 小 |
| P1 | 月度收益热力图 | 诊断季节性 | 小 |
| P1 | 基准偏离追踪 | Alpha 来源分析 | 小 |
| P2 | 交易分布 | 优化出场用 | 中 |
| P2 | 策略对比 | 选策略用 | 中 |
| P3 | plotly 交互版 | 深度探索 | 大 |
