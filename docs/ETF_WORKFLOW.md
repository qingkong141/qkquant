# ETF 当前研究与人工模拟账户流程

当前只维护 ETF 综合评分 + 市场宽度 + 三买新确认这一主策略。固定参数不依照本轮收益调优：10 个交易日调仓，偏移 0，关闭每日补空位，40% 仓位上限，4%/6%/8% 降仓与 10% 停止恢复。

## 数据与共同规则

`etf-backtest` 和 `etf-plan` 默认读取 `data/verified_etf_20260918`；可通过 `--snapshot-dir` 指定另一份通过相同审计协议的快照。核验数据库、冻结清单和交易日历哈希，固定 101 只池，隔离 159925，保留缺失日/缺失标的，并要求每日覆盖至少 95%。不回退 `data/daily.duckdb`。普通 `update-data` 不会把更新结果自动认证为可信快照。

当前快照只到 2026-09-17。观察之后日期前，要先建立新审计快照及明确新截止日的清单，保留旧快照，不能向旧前复权库直接追加或绕过日期上限。

两入口共用 `etf_portfolio_backtest.close_decision`：收盘生成次日目标；全局调仓相位由完整交易日历第 120 个预热位置起算，不因换年、评价切片或账户重启改变。每日风险减仓优先于常规调仓。修复前，调仓日常规决策可能覆盖风险减仓；本次修正属于行为变化，已保留版本记录，不宣称旧源码未变。

## 固定参数验证

```powershell
.\.venv\Scripts\qkquant.exe etf-backtest
.\.venv\Scripts\python.exe scripts\validate_verified_etf.py --snapshot data\verified_etf_20260918 --output reports\verified_validation_new --implementation-note "Shared verified input and daily decision; risk reductions take priority; fixed parameters unchanged."
```

输出目录必须不存在。普通成本和预先声明的压力成本分别运行连续账户；按年与 2026-07-22 起的历史延伸切片继承之前的现金、仓位、最高净值和调仓相位。延伸期不是真实前瞻。`etf-backtest --start` 仅额外显示评价窗口，不重新开立账户；`--end` 不得晚于快照截止日。

回测在前复权价格上模拟份额和现金，**尚非逐笔还原真实分红到账、份额折算的现金账本**，日线成交也未完整覆盖限价、涨跌停和容量。实际仓位可能随价格波动略超目标上限。此结果用于判断现有规则是否值得继续研究，不能当作真实可复制收益。

本轮 [固定参数结果](../reports/verified_validation_20260918_v1/report.md)：2024-07-04 至 2026-09-17 普通成本收益 -0.13%、最大回撤 -2.15%；压力成本收益 -0.64%、最大回撤 -2.32%。平均仓位约 2.2%，538 日中 508 日接近空仓，仅 3 次开仓。2026-07-22 起的 42 日延伸全部空仓。因此仅通过历史回撤数值检查，未证明盈利能力；本轮未启动正式模拟观察账户或自动任务。下节提供的是已经测试的人工记录接口。

## 人工模拟账户

此接口可用于逐日记录与检查规则，但没有自动填单、券商连接或推送。账户表现与研究回测分别记录。新账户必须从空仓现金开始，不导入缺少历史净值的旧真实持仓。

```powershell
.\.venv\Scripts\qkquant.exe etf-paper-init --account data\paper\etf_account.json --capital 100000
.\.venv\Scripts\qkquant.exe etf-plan --account data\paper\etf_account.json --as-of 2026-09-17
```

上例是历史日期演示，不能作为实时前瞻记录。未给 `--as-of` 时只接受当天日线；旧快照不能冒充当日计划。首日以空仓现金记录；之后**每个交易日**都提供明确的日终现金与持仓，包括确认没有成交的日子：

```json
{"cash": 100000, "holdings": {}}
```

将当日实际人工模拟记账结果保存为独立 JSON，用 `etf-plan --account-close <文件> --as-of <日期> --snapshot-dir <新快照目录>` 记录。持仓格式例如 `{"159919": 1000}`，数量单位为真实份额；不得把回测的复权模拟份额复制过来。

- 原始收盘价用于估值，前复权价只用于信号；现金、分红到账和份额折算由人工核对输入。固定资金，不进行外部入金/出金，以免扭曲回撤。
- 计划给出预算权重与仅减仓/续持时的份额上限。次日开盘股数须按当时原价、整手和可用现金计算；`max_qty` 禁止旧三买结构补仓，不能只按权重买入。
- 每日原子归档现金、持仓、净值、历史峰值、风控倍数、暂停状态、数据哈希和目标。重复同日不新增记录，也不覆盖旧记录；禁止漏日后静默重置回撤。
- 源码或固定池变化会阻断继续写入，需保留旧版本并明确处理。缺少所持标的原价时阻断估值。写入锁未释放时先人工检查中断原因，不覆盖账户。
