# 三买时间顺序与信号年龄修正

本次目的为修清信号定义，不以提高历史收益选规则。只修改现有三买实现、回测和信号计划，保留已有每日回撤控制。没有增加高位、均线乖离或距离阈值。仍是突破回踩的简化近似，不是完整缠论中枢实现。

## 修正内容

1. 强制旧高点→突破高点→回踩低点按时间排序；不成立返回 third_buy_invalid_order，不允许入场。
2. 原有左右各2根K线的分型确认机制保留。回踩低点出现时尚不能交易，要等右侧2根完成；仅确认当日返回 third_buy。
3. 之后同一结构返回 third_buy_active，不允许新开仓或加仓。已有持仓仍参与原有得分、趋势、相关性与风险筛选；不会仅因信号年龄增加而被清仓，但仍可能因其他条件被减仓或卖出。
4. 回测和 etf-plan 共用准入判断。计划增加确认后K线数、距回踩低点，JSON保留高低点日期与确认日期。缺最新行情时不发出新信号。
5. 10个交易日调仓频率、其余评分、风险参数、费用不变。仅在确认当日开仓是明确的交易时机假设，与修正时间顺序这一逻辑错误不同；本次特意增加只修顺序的对照区分影响。

结论：默认日期下只修时间顺序有所改善，但不能据此宣称未来更赚钱。严格区分事件与状态后，10日调仓错过大量确认日，仓位与交易次数显著下降；更低回撤主要伴随更低参与度，不能视为策略优势。不能把旧定义的历史业绩继续归于“新鲜三买”。

本次没有把新开仓频率改成每天，没有增加信号有效期，也没有因结果不好退回旧状态追买。若继续研究，应单独检验每日识别与10日组合再平衡的区别，并事先固定规则，不用这段历史选择最优有效期。

## 验证和限制

相关ETF测试40项通过，覆盖确认前不可见、顺序错误拒绝、旧信号不能开仓、已有持仓不因年龄被卖出、旧信号不能加仓、缺行情不重发、未来数据不改写历史前缀；保留原回撤与成交测试。

净值区间2024-07-04至2026-07-20，初始资金10万元，单边滑点0.2%、佣金0.005%、最低0.2元；同一修复后的执行引擎、同一数据池，共60组对照。仅101只股票类ETF，全部历史已参与研究；调仓偏移不是独立样本，无样本外有效性结论。执行模型仍有原有涨跌停、成交容量、分红复权等限制。

信号年龄按有效K线计数，不是自然日。严格新信号仅在回踩确认当天所有价格与背离过滤也通过时产生；若当天未通过，后续通过仍归旧状态，不补发。

etf-plan依然没有账户净值历史和固定调仓日历，不能直接当作带每日回撤控制的实盘订单。项目未连接实盘或自动下单。

## 复现

项目脚本 scripts/research_chan_timing.py 接收 --baseline-source（修正前分类器快照）及 --output。默认比较修正前后，加 --order-only 生成仅顺序修正的研究对照。旧分类器只保存在本次报告目录 baseline_classifier.py，未注册为第二套生产策略。

报告目录包含 comparison_all.csv、signal_audit.csv、每个方案的净值和成交文件；order_only子目录为顺序对照。
