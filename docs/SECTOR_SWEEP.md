# 板块强度扫板：实验性复刻

这不是原策略源码，也不提供真实下单。当前规则只是用来检验“板块共振 + 个股快速接近涨停”能否解释截图中的七笔委托；不要据此推断胜率或实际收益。

## 输入与运行

已提供9月16日分钟数据获取脚本：

```powershell
.\.venv\Scripts\python.exe scripts\fetch_sector_sweep_minutes.py --date 2026-09-16
.\.venv\Scripts\python.exe scripts\fetch_sector_sweep_minutes.py --date 2026-09-16 --all-project-universe
```

原始数据与覆盖报告写到 `data/research/`。全市场选项使用仓库自己的股票池，不是交易所当日完整名录；接口只保证最近交易日可取，不能假定以后仍能补取9月16日。分钟数据没有概念归属，不能直接传给下面的扫描器。概念成分抓取脚本在 `scripts/fetch_sector_sweep_concepts.py`，但接口反爬可能使分页缺失；只要覆盖报告存在失败页面，就不得把该成分文件当作完整板块数据。

准备覆盖**全体候选主板股票**的逐分钟 CSV。同一股票可属于多个板块，此时在同一分钟为每个板块各写一行。每条 `time` 对应**已经结束**的分钟；该分钟计算出的信号最早只能在下一分钟用于决策。

```csv
time,code,name,sector,close,prev_close
2026-09-16 09:32:00,600644,乐山电力,电力,10.31,9.44
```

上面只是字段示例，单行无法计算板块强度。不要只输入事后涨停股，否则板块上涨比例会被严重高估。

在项目根目录执行：

```powershell
$env:PYTHONPATH = 'src'
.\.venv\Scripts\python.exe -m qkquant.sector_sweep data\all_market_minutes.csv reports\sector_sweep_candidates.csv
```

输出包含每只股票的首次命中时间、所属强势板块、当时涨幅及板块强度指标。**不限制为七只**，额外候选也会完整保留。

## 当前假设阈值

- 仅扫描主板代码，股价 3–12 元，个股涨幅至少 8%。
- 板块至少 5 只成分股，上涨家数占比至少 60%。
- 板块至少 2 只上涨 7% 的股票，其中至少 1 只上涨 9.5%。
- 同一股票只记录首次触发；多板块归属选择当时较强的板块。

参数在 `SweepConfig` 中，均未经原作者确认。输入暂不包含盘口、封单、开板次数、成交量、实时板块涨速或交易限制，因此不能区分可靠封板与快速脉冲，也不能复现委托成交。要校准策略，应比较七只命中、漏选和**所有额外候选**，并使用相同时间点可见的数据。
